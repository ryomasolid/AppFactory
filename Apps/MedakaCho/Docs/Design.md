# めだか帳（MedakaCho）— 設計メモ

めだかを「容器ごと」に記録する飼育アプリ。2026-11-12 に新規作成（ニッチ飼育アプリの2本目）。
Bundle ID `tech.sesame.medakacho`・iOS 17+・iPhone 縦のみ。

## 0. 4.3 対策（はむはむ日記・げこログと違う骨格）

- **記録の単位が「容器」**（1匹ずつ追わない）。数はだいたいで持ち、★・移した・入れたで増減する。
- 中心は「水」：水温→季節の様子・えさの目安、1匹あたりの水量→過密・水換えの間隔。
- 卵は積算温度（水温×日数≒250）で孵化の目安。品種ごとの数と孵化率。
- 他アプリと同一内容の Swift ファイルは 0（md5 で確認）。

## 1. 画面

| タブ | 中身 |
| --- | --- |
| 容器 | 今日の見まわり（水換えの目安が来た容器・孵化が近い卵・総数）＋容器カード |
| 卵 | 見守り中（進み具合・孵化の目安日）／孵ったもの（孵化率） |
| 品種 | 品種ごとの総数・容器・孵化率 |
| 設定 | 朝のお知らせ（1日1通）・CSV 書き出し・広告とプライバシーの説明 |

容器の詳細: いまの様子（次の水換え・水温と季節・1匹あたりの水・30日の★）→ 11種のワンタップ記録 → 履歴（スワイプ削除で数も戻る）。
「移した」で先の容器を選ぶと、先の容器に「入れた」が自動で付く。「採卵」は卵タブにも追加できる。

## 2. 計算（`Logic/`）

- `WaterSense`: 水温 <10 冬眠／<15 ゆっくり／<20 おだやか／<28 活発／<30 高め／それ以上 高水温。
  過密は 1匹あたり 親・若魚 1L、稚魚 0.5L、針子 0.2L 未満。
  水換え間隔は 1匹あたり ≥3L 21日／≥2L 14日／≥1L 10日／≥0.5L 7日／それ未満 4日、屋外 +4日、冬は30日、28℃以上は 2/3（下限3日）。
  1週間より古い水温は目安に使わない。
- `HatchClock`: 250 ÷ 水温（切り上げ）日。15℃未満は孵らない扱い。
- `MorningDigest`: 7日先まで日ごとに組み、過ぎた水換えは今日に寄せる。何容器あっても1日1通。

## 3. データ（SwiftData）

`Vessel` 1—n `PondLog`（cascade）、`EggBatch`（置き場所は文字列）。

## 4. 起動引数

- `-sample`（メモリ上の見本・広告なし）、`-tab N`、`-openVessel`（1つ目の容器を開く）
- `-quiet`（広告・同意・ATT を起こさない。単体テストと審査用録画 scheme `MedakaChoReviewTour` で使う）
