# GeckoLog（げこログ）— 設計メモ

レオパ（ヒョウモントカゲモドキ）の多頭飼い向け飼育記録。2026-10-29 に新規作成。

## 0. なぜこの形か（4.3 対策）

このアカウントは 4.3(a) Spam で GeoHero・サブスク帳が却下されている（memory: geohero-43a-spam-rejection / subsnote-43a-resubmit）。
はむはむ日記の「種違いコピー」に見えないよう、次を守っている。

- **はむはむ日記・他アプリとコードを共有しない**。同一内容の Swift ファイルは 0（md5 で確認済み）。
- **骨格が違う**: はむはむ日記は「1匹・1日1件の日記」。げこログは「多頭・1日に何件でもつける出来事の記録」＋「次はいつ」の予測が中心。
- **レオパ固有の機能**: 給餌間隔（年齢で自動）・拒食の連続回数・脱皮周期の予測と皮残り・温湿度・産卵と温度依存の孵化日数／性別傾向。
- **1.0 は広告も課金もなし（外部 SDK ゼロ）**。「リスト＋SwiftData＋通知＋AdMob＋Pro課金」の量産テンプレ構成から外す。収益化は承認後に考える。
- **オンボーディング画面・Paywall なし**。空のケージ画面から1匹目を登録する。

## 1. 画面

| タブ | 中身 |
| --- | --- |
| ケージ | 今日の仕事（今日ごはん／脱皮が近い／見守りの数）・「ごはんをまとめて記録」・個体カード |
| きろく | 全個体の記録を日ごとに。種類・個体でしぼりこみ |
| たまご | 産卵（クラッチ）ごとの経過日数・孵化予定日・性別の傾向・孵化数 |
| せってい | ごはんの日の通知（1日1通にまとめる）・CSV 書き出し |

個体の詳細: いまの様子（次のごはん・最後に食べた・次の脱皮・体重）→ 8種類のワンタップ記録 → 体重グラフ → 履歴。

## 2. 計算（`Logic/`）

- `CareRhythm`: 年齢区分（〜4か月ベビー／〜1歳ヤング／アダルト）、給餌間隔 1/2/4 日、次のごはん＝最後に与えた日＋間隔（拒食でも進む）、
  拒食の連続回数、脱皮予想＝直近3回の間隔の平均（1回だけなら年齢の目安 10/21/35 日）、体重の30日比。
- 見守り: 拒食2回以上・14日食べていない・1か月で -10% 以上。
- `Incubation`: 温度→孵化日数の表（26℃ 65日〜33℃ 38日）を線形補間。性別傾向は ≤29.5 メス多め／〜31 混在／〜33 オス多め。
- `FeedingAlarm`: 7日先まで「日ごと」に組み立て、何匹いても1日1通。起動・復帰・記録保存のたびに全消し→組み直し。

## 3. データ（SwiftData）

`Gecko`（個体）1—n `CareEntry`（記録・cascade）、`Clutch`（産卵・母は名前の文字列で持つ）。

## 4. スクショ用起動引数

`-showcase`（メモリ上の見本データ・端末の記録に触れない）、`-tab N`、`-openGecko`（1匹目の詳細を開く）。
