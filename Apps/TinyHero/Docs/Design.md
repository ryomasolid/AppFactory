# TinyHero（ちいさな勇者）— 試作の設計メモ

レトロな一人旅のコマンドRPGの試作。フィールドを歩き、ランダムに出る敵とコマンドで戦い、レベルを上げて洞窟のボスを倒すと終わる。
まずシミュレータ／実機で遊べる形を作るのが目的で、課金・広告・ストア文書は公開を決めてから足す。

> 実装状況（2026-09-15）: v0.1 の1本道（村・野原・洞窟2階・ボス・エンディング）を実装。テスト 24 件が通る。
> シミュレータで村・野原・洞窟・戦闘の表示を確認済み。未確認: 通しで遊んだときの難易度、実機での操作感。

## 1. 方針

- **仕組みだけ借りて、中身はオリジナル**。既存タイトルの名前・キャラクター・呪文名・音楽・画面の見た目は使わない
  （権利とストア審査 4.1 / 5.2 のため）。呪文は「ヒール／ファイア」、コマンドは「こうげき／まほう／どうぐ／にげる」。
- **外部素材なし**。絵はすべて 16×16 のドット絵をコードの文字列で持ち、起動時にビットマップへ焼く（`PixelArt.swift`）。
- **30分〜1時間でクリアできる小ささ**。一人旅・装備は武器と鎧だけ・消耗品は薬草だけ。
- **ロジックと画面を分ける**。戦闘（`Battle`）・マップ（`GameMap`）・成長（`Hero`）は SwiftUI に依存しない純粋な型にし、テストで固める。

## 2. 構成

| ファイル | 役割 |
| --- | --- |
| `Game/Hero.swift` | レベル表・呪文・道具・勇者の能力値とレベルアップ |
| `Game/Enemy.swift` | 敵の能力値（ボス含む） |
| `Game/Battle.swift` | 1対1のコマンド戦闘。1コマンドで1ターン進め、メッセージと決着を返す |
| `Game/Random.swift` | 乱数の差し替え（本番はシステム乱数、テストは種付き・固定） |
| `Game/World.swift` / `Maps.swift` | 地形・ワープ・人・宝箱・ボス。地図は文字列で書く |
| `Game/GameState.swift` | 画面遷移・移動・会話・宿屋・店・戦闘メッセージの進行・セーブ |
| `Game/PixelArt.swift` ほか `*Art.swift` | ドット絵の定義と描画キャッシュ |
| `Game/Launch.swift` | 起動引数で途中の場面から始める |
| `Views/` | タイトル・フィールド（マップ・十字キー）・戦闘・メニュー／店／宿屋・エンディング |

## 3. 遊びの流れ

1. **はじまりの村**：長老が目的を話す。宿屋（`2 + LV×3` G、泊まると自動セーブ）と店（薬草・剣・鎧）。
2. **ひろの**：村の近くの草原は弱い敵、森・丘ほど強い。川の橋を渡って北東の丘へ。
3. **ヤミのどうくつ B1**：宝箱（150G）。下り階段へ。
4. **ヤミのどうくつ B2**：宝箱（鋼の剣）。奥のヤミドラゴンに A で話しかけると戦闘。逃げられない。
5. 倒すとエンディング。全滅すると村の入口に戻り、所持金が半分になる。

遭遇は、敵の出る地形を歩いたとき 1/14。戦闘の直後4歩は出ない。

## 4. 操作

- 画面下の十字キー（指を滑らせて向きを変えられる。押している間は歩き続ける）。
- A：目の前の人と話す・宝箱を開ける・会話を送る。B：メニュー（つよさ・じゅもん・どうぐ・セーブ）。
- 戦闘はウィンドウのコマンドをタップ。

## 5. 起動引数（表示確認用）

```
-startMap field -startX 8 -startY 7     # 野原の橋の手前から
-startMap cave2 -startX 6 -startY 3 -startLevel 10   # ボスの前から（LV10・500G）
-startBattle goblin -startLevel 5       # いきなり戦闘
```

## 6. 次にやること（候補）

- 通しで遊んで難易度を調整する（ボスに挑む目安は LV9〜10・鋼の剣・鎖帷子）
- 効果音と BGM（オリジナルで作る）、被ダメージ時の画面の揺れや敵の点滅
- 勇者の向き（4方向）の絵、町の中の家の入口
- 公開するなら：アイコン、ストア文書、広告／買い切り（追加ダンジョンなど）
