# ムダゼロ（MudaZero）— 設計メモ

ムダ遣いしなかった日を1タップでしめて、ムダゼロの日をふやす節約アプリ。2026-11-18 に新規作成（間食ストップのように「毎日開く」アプリとして）。
Bundle ID `tech.sesame.mudazero`・iOS 17+・iPhone 縦のみ・無料＋AdMob バナー。

## 0. 4.3 対策（間食ストップとの違い）

- 記録は「した／しない」ではなく、出費を **ついつい（ムダ）／必要** に分けて金額でつける。必要な出費だけの日もムダゼロ。
- 日の結果は4つ：0円の日（金）・ムダゼロ（必要だけ・緑）・ついつい（金額）・まだ。
- 中心は「今月のムダ予算 → 1日あと何円まで」と「浮いたお金（ふだんのムダ × がまんした日）→ ためる もくひょう」。
- カレンダーは月のふりかえり（日数・合計・ついつい の内訳）。
- 他アプリと同じ内容の Swift ファイルはなし（広告まわりも書き直し）。

## 1. 画面

| タブ | 中身 |
| --- | --- |
| きょう | ムダゼロ連続日数＋今月の0円の日/ムダゼロ → きょうをしめる／お金を使った → 使ったお金 → ムダ予算 → もくひょう |
| カレンダー | 月の色分け（タップでその日を開いて追加・しめる・取り消し）→ ふりかえり |
| 設定 | ふだんのムダ・ムダ予算・もくひょう・夜のお知らせ（18〜23時・しめていない日だけ）・プライバシー |

はじめての起動（Hello）で ふだんのムダ（300〜1500円）とムダ予算（5000〜30000円）を選ぶ。

## 2. しくみ（`Logic/Book.swift`）

- ついつい が1件でもあれば ついつい。なければ、しめた日だけ 0円の日／ムダゼロ。
- 連続：きょうがまだなら、きのうから数える。
- 浮いたお金：ムダゼロの日は ふだんのムダ、ついつい の日は max(0, ふだんのムダ − ついつい)。もくひょうを保存した日から数える。
