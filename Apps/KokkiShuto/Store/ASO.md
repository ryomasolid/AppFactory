## プロモーションテキスト

```
国旗を見て国名を、国名を見て首都を。4択でテンポよく解いて、3回つづけて正解したら「覚えた」。まちがえた国はまた出るので、197か国が少しずつ頭に入ります。広告なし・無料。
```

## 説明文

```
国旗と首都は、世界197か国の「国名・首都・国旗」の3つを覚えることだけに絞った4択クイズです。

■ 出し方は4つ
・国旗 → 国名
・国名 → 国旗
・国名 → 首都
・首都 → 国名
「まぜる」で4つをまぜて出題することもできます。

■ なんとなくでは当たらない選択肢
まちがいの選択肢は、同じ地域の国から選びます。
ヨーロッパの似た国旗、アフリカの似た首都など、ちゃんと見分ける力がつきます。

■ 3回つづけて正解で「覚えた」
国旗・首都それぞれ、続けて3回正解するとその国は「覚えた」に。
まちがえるとやり直しなので、まぐれでは覚えたになりません。
覚えた数は 197か国中いくつ、とホームでひと目でわかります。

■ にがてな国を集中して
出題は、まだ覚えていない国・まちがえた国が優先。
「にがてな国旗」「にがてな首都」では、まちがえたことのある国だけを出します。

■ 地域をしぼって
アジア・中東・ヨーロッパ・アフリカ・北中米・南米・オセアニアから選べます。
1回の問題数は10・20・30問。すきま時間にサクッと解けます。

■ ずかん
すべての国の国旗・国名・首都を一覧で見られます。地域でしぼったり、国名や首都で検索したりできます。
ボリビアや南アフリカなど、首都の扱いが特殊な国には補足つき。

■ 収録している国
国連加盟の193か国に、バチカン・コソボ・クック諸島・ニウエを加えた197か国。
国名と首都は日本の外務省の表記に合わせています。

■ 安心して使える
広告なし・アプリ内課金なし・登録なし。通信もしません。
記録は iPhone の中だけに保存されます。
```
