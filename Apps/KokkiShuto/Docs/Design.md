# 国旗と首都（KokkiShuto）

国名・首都・国旗の3つを覚えることだけに特化した4択クイズ。

## 1. 中身

- 197か国（国連加盟193＋バチカン・コソボ・クック諸島・ニウエ）。国名・首都は外務省の表記。データは `Sources/Model/Country.swift`。
- 国旗は絵文字（ISO コードから作る）。画像は持たない。
- 出し方は4つ：国旗→国名／国名→国旗／国名→首都／首都→国名。「まぜる」で4つを混ぜる。どれも4択。
- まちがいの3つは、2つを同じ地域から選ぶ（見分ける力がいるように）。チャド/ルーマニア・インドネシア/モナコは同時に出さない（絵文字ではほぼ同じ）。
- 記録は国ごと×（国旗・首都）。続けて3回正解で「覚えた」、まちがえると0に戻る。出題は覚えていない国・まちがえた国を優先。
- 「にがてな国旗／首都」：まちがえたことがあって、まだ覚えていない国だけで出題。
- ずかんタブ：地域で絞る・国名/首都で検索・覚えた印。首都が特殊な国（ボリビア・南アフリカ・イスラエルなど）は補足を出す。
- 記録は UserDefaults（`progress.v1`）。課金なし。
- 広告（1.0.1〜）：「クイズ」「ずかん」タブの下にバナー（`Sources/Ads`）。クイズ中の全画面には出さない。子ども向けとしてリクエスト（TFCD・TFUA・G）・ATT なし・同意フォームも出ない。Debug と TestFlight はテスト用ユニット。`-noAds`・`-demo` では出さない（テストと録画のスキームは `-noAds` 付き）。
  AdMob アプリ `~7450487203`（2026-11-20 に App Store へ紐づけて登録）・バナー `/4371404436`。

## 2. 起動引数（スクショ用）

- `-noAds`（広告なし）、`-demo`（記録の見本・保存しない・広告なし）、`-tab N`（0 クイズ / 1 ずかん）、`-quiz <Mode の rawValue>`（起動してすぐ出題）、`-answered`（1問目をまちがえた形）
