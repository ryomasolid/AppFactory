## 説明文（最大4000字）
```
クルマにいくらかかっているか、ちゃんと答えられますか。

カーログは、給油の記録から「燃費」「維持費」「次のメンテ時期」までをまとめて面倒みるアプリです。入力するのは給油のたびに4つだけ。日付・走行距離・給油量・金額。あとは全部アプリが計算します。

■ こんな人に
・燃費が良くなったのか悪くなったのか、なんとなくでしか分かっていない
・車検やオイル交換の時期を毎回ディーラーからの連絡で知る
・クルマに年間いくら使っているかを把握して、買い替えや維持の判断に使いたい
・レシートは取ってあるが、計算はしたことがない

■ 給油を入れるだけで燃費が出ます
満タン給油から次の満タン給油までの距離と給油量から、区間ごとの燃費を自動で計算します（満タン法）。途中の継ぎ足し給油もそのまま入れて大丈夫です。区間燃費と通算燃費の両方が出るので、「最近落ちてきた」がはっきり分かります。

■ 維持費をカテゴリごとに
ガソリン代・自動車税・任意保険・車検・駐車場・洗車・パーツ・修理・高速代。カテゴリ別の合計と月ごとの推移をグラフで表示します。1kmあたりいくらかかっているかも出るので、他の移動手段と比べられます。

■ 次のメンテを、根拠つきで通知
オイル交換は「6か月または5,000km」のように、期間と距離の両方で管理できます。走った距離のペースから到達日を予測するので、距離ベースの項目もちゃんと事前に通知が届きます。車検・タイヤ交換・バッテリー・保険更新などのテンプレートを用意しました。

■ 主な機能
・給油記録と満タン法による燃費計算（区間燃費／通算燃費）
・維持費をカテゴリ別に記録、月別・年別の集計とグラフ
・1kmあたりのコスト、月平均コスト
・メンテナンス項目を期間・距離で管理し、期限前に通知
・実施履歴の記録（いつ・何km・いくら）
・複数のクルマを登録して切り替え（Pro）
・記録のCSV書き出し（Pro）

■ ここがポイント
燃費だけのアプリ、家計簿だけのアプリ、リマインダーだけのアプリ——どれも1つでは続きません。カーログは「給油の記録」という一番発生頻度の高い入力を起点に、コスト集計もメンテ時期の予測もまとめて動かします。入れる手間は1回ぶんのままです。

■ 安心・プライバシー
・記録はすべて端末内に保存され、外部サーバーへ送信されません
・アカウント登録も位置情報も不要です

※ 通知の利用には通知の許可が必要です。
※ 無料版では広告（Google AdMob）を表示します。登録できるクルマは1台、メンテナンス項目は3件までです。給油・維持費の記録件数と、燃費・コストの計算に上限はありません。
※ Pro（買い切り）でクルマとメンテナンス項目が無制限になり、CSV書き出しが使え、広告が非表示になります。
```

## スクリーンショット構成（6.9" = 1320×2868／iPhone のみ）
撮影は `simctl launch` + 起動引数で再現可能（広告非表示・ATT無し・デモ値入り）。
※ 6.5"（1242×2688）も必要。6.9" から `sips` で変換する（`Docs/Design.md` の提出手順を参照）。

1. **01_home** … 平均燃費を主役に、今月の出費・1kmあたり・期限が近いメンテ（`-demo -hideAds`）
2. **02_fuel** … 給油一覧。区間燃費が各行に並ぶ ＝ 入力の見返りが一目で分かる（`-demo -hideAds -startTab fuel`）
3. **03_entry** … 給油入力シート。入力項目が4つだけであることを見せる（`-demo -hideAds -showFuelEntry`）
4. **04_cost** … カテゴリ別の内訳と月別推移グラフ（`-demo -hideAds -startTab cost`）
5. **05_maintenance** … 「6か月または5,000km」の次回予定と残り（`-demo -hideAds -startTab maintenance`）
6. **06_paywall** … Pro の内容（`-demo -hideAds -showPaywall`）
