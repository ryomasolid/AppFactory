## 説明文（最大4000字）
```
その定期、買った方がお得？都度払いのままがお得？——迷いをスッキリ解消。

定期チェックは、通勤・通学の定期券を「買うべきか」を数字で判定するシンプルな計算アプリです。片道の普通運賃と定期代を入力するだけで、何往復で元が取れるか、今の通勤ペースで得か損かが一目でわかります。

■ こんな人に
・定期を買うか、都度払い（IC・きっぷ）のままか迷っている
・在宅勤務やシフト勤務で、月の通勤日数が読めない
・引っ越し・転職・進学で通勤ルートが変わった
・定期区間内のお出かけも多く、実はもっとお得かも？と思っている

■ 主な機能
・片道運賃・定期代・期間（1／3／6ヶ月）・月の通勤日数から損益を自動計算
・「元が取れる往復回数」を大きく表示
・「買うべき／トントン／都度払いがお得」をわかりやすく判定
・定期区間内の追加利用（途中下車での買い物・区間内の駅での用事など）を元取りに加算
・計算した区間を保存して、後から見返せる履歴機能

■ ここがポイント
定期のいちばんの魅力は「区間内が乗り放題」なこと。通勤だけでは元が取れなくても、休日のお出かけや途中下車を足すと元が取れるケースは多くあります。定期チェックは、その「区間内で浮く運賃」も計算に入れて、本当にお得かを判定します。

■ 安心・プライバシー
・入力したデータはすべて端末内に保存され、外部サーバーへ送信されません
・アカウント登録は不要です

※ 一部の快適機能・広告非表示は Pro（買い切り）で解放されます。

※ 本アプリは運賃の目安を計算するツールです。実際の運賃・定期代は各鉄道・バス事業者の公式情報をご確認ください。
```

## スクリーンショット構成（6.9" = 1320×2868 で撮影済み・Store/screenshots/）
撮影は `simctl launch` + 起動引数で再現可能（広告非表示・ATT無し・デモ値入り）。
推奨の並び順（先頭ほど重要。検索結果では最初の1〜3枚が表示される）:

1. **02_result** … 計算結果「定期を買うべき！／20往復」＝アプリの価値が即伝わる主役（`-demo -hideAds`）
2. **01_onboarding** … 3つの特徴で機能を要約（`-hideAds -forceOnboarding`）
3. **05_extra** … 通勤だけなら赤字→区間内のおでかけで黒字化＝独自価値（`-demoExtra -hideAds`）
4. **03_history** … 保存した区間の履歴＝実用性（`-demo -hideAds -startTab history`）
5. **04_paywall** … Pro（広告非表示）紹介（`-demo -hideAds -showPaywall`）

※ 6.5"/5.5" は任意。6.9" があれば提出可。
※ 本アプリは iPad 対応（Universal）のため、**13" iPad（2064×2752）も必須**。
  → `Store/screenshots-ipad/` に同じ5枚を用意済み（同じ起動引数で撮影）。
※ IAP 審査用スクショには 04_paywall を流用可。
