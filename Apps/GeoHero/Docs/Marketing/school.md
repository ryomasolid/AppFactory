# 先生・保護者 向けの 紹介文

```
遊びながら北海道の地理が身につくRPG「地理の勇者」

iPhoneで遊べる無料のゲームです（広告・課金・通信なし）。
函館・札幌・小樽・知床など北海道の9つの街を歩き、街の人の話や名所の看板から
五稜郭、松前城、小樽運河、知床五湖、流氷、アイヌの言葉などを知ることができます。
戦闘中には地理のクイズが出て、正解すると有利になるので、子どもが自分から話を読みにいきます。

・小学校4年の社会（都道府県・地域の学習）や、北海道の地域学習の導入に
・夏休みの自由研究「ゲームに出てきた名所を調べてみよう」に
・30分〜数時間で遊べ、途中でセーブできます

App Store: https://apps.apple.com/jp/app/id6813561253
```
