# Apple 検索広告（少額で 試す案）

**お金が かかるので 本人が 決める。** 無料アプリで 収入が ないため、まずは 少額で 反応を 見る。

- 種類: Apple Ads Basic（入札不要・インストール単価の上限だけ決める）
- 月予算: 5,000〜10,000円
- 国: 日本のみ（ゲームが 日本語だけのため）
- インストール単価の上限: 100〜150円
- 2週間 回して、インストール単価と 残る率（アナリティクスの「保持」）を 見る。高ければ 止める。

Advanced を 使うなら キーワード案: 地理 ゲーム / 地理 クイズ / 北海道 ゲーム / ドット絵 RPG / 都道府県 ゲーム / 社会 勉強 アプリ
