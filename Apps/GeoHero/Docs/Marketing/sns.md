## 動画（TikTok・YouTube ショート・リール、15〜30秒）

シミュレータで 撮れる（`xcrun simctl io booted recordVideo out.mp4`）。

1. 0〜3秒: タイトル → 「北海道を歩いて地理を覚えるRPG」
2. 3〜10秒: 函館の街を歩く → 看板を読む（スタンプの音）
3. 10〜18秒: 戦闘 → 「ちしきのチャンス！」→ 正解して おいうち
4. 18〜25秒: 飛行機で 移動 → 「札幌・小樽」の札
5. 25〜30秒: ストアの リンク・「無料・広告なし」

起動引数で 場面を 呼べる（`-startMap` `-startBattle` `-battleSubmenu quiz` など。`Launch.swift` を見る）。
