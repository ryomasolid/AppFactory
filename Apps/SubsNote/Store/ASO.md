# SubsNote（サブスク帳）— App Store 掲載文（下書き）

> 文字数は全角=1, 半角=1 で概算。App Store Connect 入力時に各上限を最終確認すること。
> 設計・画面構成は `Docs/Design.md` を参照。

## 競合（2026-09 時点・App Store 日本）
| アプリ | 強み | 弱み（＝こちらの勝ち筋） |
| --- | --- | --- |
| サブスク管理 - 1日いくら使っている？（ドットインストール） | 知名度・「1日いくら」の見せ方・更新日通知 | 買い切り有料（¥300〜500）で最初の1件を試せない |
| Costly | シンプルなUI・更新日通知 | 無料体験の終了を別扱いしていない |
| SubsHub | iPhone で完結 | 支払い方法ごとの解約場所まで持っていない |
| SubKeeper / LUFT | PC でも見られる | アカウント登録が前提。端末内で済ませたい人には重い |
| Bobby（海外） | 定番・買い切り | 英語発。日本のキャリア決済・PayPay などの支払い方法が無い |

**差別化の軸は3つ**:
1. **無料体験の終了を無料で・強めに通知**（一番お金を失う場面を最優先で守る）
2. **支払い方法ごとの「どこで解約するか」**（App Store・キャリア決済・Amazon などで解約場所が違う）
3. **解約で浮いた額を見せる**（解約を記録すると「年 ¥11,760 浮いています」）

## App 名（最大30字）
- **案A（推奨）: `サブスク帳 解約忘れ防止・更新日を通知`**（19字）
- 案B: `サブスク帳 サブスク管理と無料体験の通知`（20字）
- 案C: `サブスク帳 月額まとめて管理・解約忘れ防止`（21字）

※ 「サブスク」「解約」「更新日」はそれぞれ単独で検索される語。
※ 表示名（CFBundleDisplayName）は `サブスク帳`（5字）。App Store Connect で名前が取られていたら `サブスクノート` を次点にする。

## サブタイトル（最大30字）
`契約中のサービスと更新日をひと目で管理`（19字）

※ 旧案 `無料体験の終了も月額の合計もひと目で分かる` は 2.3.7 でリジェクト（下記）。
   サブタイトルには「無料」「月額」など値段にかかる語を入れない。無料体験の訴求は説明文とプロモーションテキストで行う。

## プロモーションテキスト（最大170字・審査なしで随時変更可）
`毎月いくら払っているか、すぐ分かる。サブスクの更新日と無料体験の終了日の前にお知らせするので、解約し忘れて本契約になるのを防げます。月払いも年払いも「月あたり」「1日あたり」にそろえて表示。記録はすべて端末内に保存され、口座やカードとの連携もありません。`

## 説明文（最大4000字）
```
毎月いくら、サブスクに払っていますか。

サブスク帳は、動画・音楽・クラウド・AI・ジムなどのサブスクをまとめて、次の支払日と無料体験の終了日の前にお知らせするアプリです。サービス名を選ぶだけで登録でき、月払いも年払いも「月あたりいくら」にそろえて見せます。

■ こんな人に
・無料体験のつもりが、気づいたら本契約になっていた
・年払いのサブスクが自動更新されてから気づいた
・毎月の引き落としが、何の支払いか分からない
・いくつ契約しているか、全部は思い出せない

■ 解約し忘れを防ぐ通知
支払日の3日前と前日にお知らせします。無料体験は終了日の3日前と前日に、続けない場合は今日中に解約するよう知らせます。タイミングと時刻は設定で変えられます。

■ 合計がひと目で分かる
週払い・月払い・年払いが混ざっていても、月あたり・年あたり・1日あたりの金額にそろえて表示。今月これから引き落とされる金額も分かります。

■ 登録はサービスを選ぶだけ
よく使われるサービスを選ぶと、料金プランの候補と支払い周期、解約の手順が入ります。金額と次の支払日を確かめて保存するだけ。リストにないサービスも手で追加できます。

■ どこで解約するか分かる
App Store・キャリア決済・Amazon・クレジットカードなど、支払い方法ごとに解約する場所が違います。サブスクごとに解約の手順をメモしておけます。

■ 主な機能
・サブスクの一覧（次の支払い順・金額順・名前順）
・支払日と無料体験終了の通知
・月あたり／年あたり／1日あたりの合計
・支払いカレンダー
・解約済みの記録と、解約で浮いた金額
・カテゴリ別・支払い方法別の内訳（Pro）
・CSV書き出し（Pro）

■ 安心・プライバシー
・記録はすべて端末内に保存され、外部サーバーへ送信されません
・銀行口座やクレジットカードとの連携はありません
・アカウント登録は不要です

※ 表示される料金プランの候補は目安です。実際の金額はご契約内容をご確認ください。
※ 通知の利用には通知の許可が必要です。
※ 無料版では広告を表示します。登録できるサブスクは5件までです（解約済みは数えません）。通知と合計・カレンダーは無料でお使いいただけます。
※ Pro（買い切り）で登録件数が無制限になり、内訳とCSV書き出しが使え、広告が非表示になります。
```

## スクリーンショット構成（6.9" = 1320×2868／iPhone のみ）
撮影は `simctl launch` + 起動引数で再現可能（`-demo -hideAds -fixedToday 2026-09-14`）。
デモのサービス名は架空（「動画プラス」「ミュージックワン」など）。6.5"（1242×2688）は `sips` で変換する。

1. **01_home** … 月あたりの合計と次の支払いの一覧
2. **02_trial** … 無料体験の終了通知の例（オンボーディングの2ページ目・`-forceOnboarding -onboardingStep 2`）
3. **03_calendar** … 支払いカレンダー（`-startTab calendar`）
4. **04_detail** … 詳細（今後の支払日と解約の手順・`-showDetail`）
5. **05_breakdown** … カテゴリ別・支払い方法別の内訳（`-showBreakdown`）
6. **06_paywall** … Pro の内容（`-showPaywall`）
